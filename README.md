# Proyecto Web – GitHub Pages

Este proyecto consiste en la creación y publicación de una página web estática utilizando **GitHub Pages**, como práctica de alojamiento web.

La web está desarrollada con **HTML, CSS y JavaScript**, y cumple los criterios indicados en la tarea.

## 🌐 Enlace a la web
👉 https://TUUSUARIO.github.io

## 🛠 Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- GitHub Pages

## ⚙️ Funcionalidades JavaScript
- Intercambio de imágenes al hacer clic sobre ellas
- Campo de texto interactivo que modifica contenido de la web
- Objeto en movimiento mediante JavaScript

## 🎨 Estética
La estética de la página está inspirada en webs actuales, concretamente:
- *El CO₂ en el cambio climático – EL PAÍS*
